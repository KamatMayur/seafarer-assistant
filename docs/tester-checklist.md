# Tester checklist – Seafarer Assistant (test version)

Please work through this over **1–2 weeks** of normal use. For anything that is wrong, confusing or missing, use
**Settings → Report a problem** in the app (it attaches the app version). At the end we will ask you the short
questions in section E.

Your profile (fill in): department ____ · level ____ · rank ____ · home MMD ____ · exams you are preparing for ____

## A. First day (about 20 minutes)
- [ ] Install with the guide. Anything unclear? Note the step.
- [ ] Sign in with the email code. Did the code arrive within a minute? (Check spam.)
- [ ] Fill in the profile. Is your rank / MMD / exam grade in the lists?
- [ ] Look at **For you**. For each of the first 5 cards: does it really concern you? Is the "Why" line right?
- [ ] Is there a circular from the last 30 days that **should** be there for you but is missing? (Tell us which.)
- [ ] Open 3 documents. Are "Who is affected", "What you must do" and "Deadline" right compared with the official
      PDF? (Use **Open official PDF**.)
- [ ] Add your real certificates in **Wallet** with expiry dates. (Numbers are optional.) Are the "days left" right?
- [ ] Search the **Archive** for something you know, e.g. "CoC revalidation" or a circular number.

## B. During the test (normal use)
- [ ] Leave the app in the tray. When a new circular comes out, did you get a Windows notification? How long after
      it appeared on the DGMA site?
- [ ] Did you get a notification for something that does **not** concern you? (Report it with the title.)
- [ ] Use it once with **no internet** (or Wi-Fi off): can you still read the feed, opened documents and your wallet?
      Add a certificate offline, reconnect: is it still there and not duplicated?
- [ ] Try **Settings → Topics**: follow "CoC dispatch lists" if you are waiting for a CoC; mute something you don't
      want. Did the feed change as expected?
- [ ] Try **quiet hours** and **data saver** if they matter to you.
- [ ] If you have two Windows PCs: sign in on both, edit the same certificate on both. What happened?

## C. Things that must never happen (tell us immediately)
- A summary that **contradicts** the official PDF (wrong date, wrong group, wrong deadline).
- A missed **critical safety / security advisory**.
- Someone else's data, or your certificate scan, appearing anywhere it shouldn't.
- The app crashing or not opening.

## D. Privacy checks (5 minutes, near the end)
- [ ] **Settings → Download my data**: open the ZIP. Is it what you expected?
- [ ] Read **Settings → Privacy notice**. Anything unclear or worrying?
- [ ] (Optional, at the very end) **Settings → Delete my account**, then try to sign in again: everything should
      be gone.

## E. End-of-test questions
1. How many alerts per week did you get? Too many / about right / too few?
2. Out of 10 alerts, how many were really relevant to you?
3. Were the summaries useful, or did you always need the PDF? Would plain-language summaries matter to you?
4. Which language would you prefer the app and summaries in?
5. What one feature would make you use this every week? (Ideas: exam countdowns, fake-agency (RPSL) check, sea
   time / NRI days calculator, certificate scan, PDF export for crewing agencies, mobile app.)
6. Would you pay for it? If yes, roughly how much per year?
